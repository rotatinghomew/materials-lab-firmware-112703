# 固件上线人员身份与审批证据

厂商发布、线站确认、设备安装窗口和回执的本地资料以 JSON 保存，全部身份、系统与输入均为合成。资料服务只回放各参与方提供的事实。

需要 Python 3.11 和 OpenSSL 3。运行 `python3 -m unittest discover -s tests -v` 核对项目资料和本地接入。运行 `python3 replay.py` 启动回放服务，默认监听 `127.0.0.1:8765`。访问 `/streams` 查看资料名称，`/streams/名称` 读取相应资料，`/timeline?through=60` 读取截至演练时刻 60 收到的事件。也可直接读取 `data/` 中的原始文件。

签名来源的核对使用 OpenSSL 3。

## 资料约定

identities 的 subject 在其 authority 内唯一，person 是双方各自确认后用于判断同一人的设施编号。packages 的 artifact 路径指向合成文本工件，字节用于核对厂商材料，仿真节点不会加载执行。节点时间窗左闭右开。timeline 提供厂商、值班和设备节点分别产生的记录，设备接受与开始是两个不同的状态。
厂商发布证明位于 proofs，*.json 为签名覆盖的原始字节，*.sig 为 Ed25519 二进制签名，签发公钥在公开目录中。清单列摘要和包号，登记记录仍要校对发布人所属单位。记录中的时间用本地演练时钟。
